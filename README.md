# XA Browser Extensions

A collection of tools for Brave. Each extension has its own repository with screenshots, installation instructions, and usage examples. The repositories are private, so their links open for people with access.

| Extension | What you can do |
| --- | --- |
| [XA Snap](https://github.com/xa-btc/xa-snap) | Capture a full page or selected region, annotate it, and export an image or PDF. |
| [XA Text Multi Search](https://github.com/xa-btc/xa-text-multi-search) | Highlight several words or phrases at once and jump between matches by color. |
| [XA Image](https://github.com/xa-btc/xa-image) | Right-click an image or thumbnail to run a reverse image search with your chosen provider. |
| [XA Refresh](https://github.com/xa-btc/xa-refresh) | Schedule per-tab reloads and watch a page for text, elements, or content changes. |
| [XA Volume](https://github.com/xa-btc/xa-volume) | Adjust, boost, or mute an individual tab while other tabs keep their volume. |
| [XA Paramount Quality](https://github.com/xa-btc/xa-paramount) | See the current playback resolution and choose from the available Paramount+ stream qualities. |
| [XA Netflix Ad Skipper](https://github.com/xa-btc/xa-netflix-ad-skipper) | Skip intros and recaps, handle playback prompts, and fast-forward recognized timed ads. |
| [XA Extension Observation](https://github.com/xa-btc/xa-extension-observation) | Inspect installed extensions, review permission changes, and diagnose tab errors or unexpected reloads. |
| [XA Wallet Maintainer](https://github.com/xa-btc/xa-wallet-maintainer) | Organize public EVM and Solana accounts, check balances, and review transfers for wallet approval. |

## Install an extension

Open its repository and download or clone the project. In Brave, open `brave://extensions`, enable **Developer mode**, choose **Load unpacked**, and select the project’s `extension` folder. Follow the project README for any additional setup.

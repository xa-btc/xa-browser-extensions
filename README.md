# XA Browser Extensions

A collection of ten extensions for Brave. Select an extension below to open its project folder.

| Extension | What you can do |
| --- | --- |
| [XA Snap](XA%20Snap/) | Capture a full page or selected region, annotate it, and export an image or PDF. |
| [XA Text Multi Search](XA%20Text%20Multi%20Search/) | Highlight several words or phrases at once and jump between matches by color. |
| [XA Image](XA%20Image/) | Right-click an image or thumbnail to run a reverse image search with your chosen provider. |
| [XA Refresh](XA%20Refresh/) | Schedule per-tab reloads and watch a page for text, elements, or content changes. |
| [XA Translation](XA%20Translation/) | Translate page text, video captions, and on-screen video text. |
| [XA Volume](XA%20Volume/) | Adjust, boost, or mute an individual tab while other tabs keep their volume. |
| [XA Paramount Quality](XA%20Paramount/) | See the current playback resolution and choose from the available Paramount+ stream qualities. |
| [XA Netflix Ad Skipper](XA%20Netflix%20Ad%20Skipper/) | Skip intros and recaps, handle playback prompts, and fast-forward recognized timed ads. |
| [XA Extension Observation](XA%20Extension%20Observation/) | Inspect installed extensions, review permission changes, and diagnose tab errors or unexpected reloads. |
| [XA Wallet Maintainer](XA%20Wallet%20Maintainer/) | Organize public EVM and Solana accounts, check balances, and review transfers for wallet approval. |

## Install an extension

Download or clone this repository. In Brave, open `brave://extensions`, enable **Developer mode**, choose **Load unpacked**, and select the `extension` folder inside the project you want. Check the project README, where available, for additional setup.
